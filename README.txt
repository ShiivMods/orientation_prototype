ORIENTATION PRO - V0.9

Handicap(s) est désormais une sélection structurée.

Deux niveaux distincts :
1. Handicap(s) déclaré(s), pour conserver l'information choisie par l'utilisateur.
2. Impacts fonctionnels, qui influencent réellement le matching métier.

Exemples d'impacts fonctionnels :
- conduite professionnelle impossible
- station debout / marche
- port de charges
- gestes fins
- écran / repérage visuel
- téléphone / communication orale
- bruit
- déplacements
- travail de nuit
- cadence soutenue
- besoin de pauses régulières

Fonctionnement :
- Une limitation explicitement incompatible avec une exigence essentielle peut écarter le métier des recommandations.
- Les métiers écartés peuvent être réaffichés volontairement avec le filtre « Handicap & accessibilité ».
- Les situations pouvant nécessiter un aménagement réduisent le score et affichent une alerte.
- Pour les professions à aptitude médicale réglementée, Orientation Pro affiche « Aptitude réglementée à vérifier » au lieu de prononcer une inaptitude.
- Le métier « Conducteur de bus / autocar » a été ajouté comme cas de démonstration.

Ce prototype ne remplace pas un avis médical, une étude de poste ou l'examen réglementaire d'aptitude.

Cas conduite réglementée : cécité déclarée = métier écarté ; malvoyance = aptitude médicale à vérifier.
